# CampusFix

## ICS 2314 Software Engineering Semester Project

CampusFix is a software engineering project for developing a prototype system for reporting and managing university facilities maintenance problems.

The system is intended to help university users report facility problems and allow maintenance requests to be managed from reporting through resolution and closure.
